# חיים של אחרים — אפליקציה (React + Supabase)

גרסה דינמית של lives-of-others.com עם מערכת ניהול.

- `npm run dev` — פיתוח מקומי (צריך `.env.local` עם `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`)
- `supabase/migrations/` — מבנה ה-DB (פריסה: `supabase db push`)
- אחסון: Vercel · מסד נתונים: Supabase (eu-central-1)
